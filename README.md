# mango-order — 芒果訂購網站

一頁式芒果線上訂購系統，使用靜態網站 + Google Sheets 作為後端，零伺服器成本。

## 功能

- 商品從 Google Sheet 動態載入，三種規格（五斤/十斤/二十斤），未填價格自動隱藏
- 售罄商品灰掉不可選購
- 即時計算訂單總金額
- 訂購人 / 收件人分開填寫，可勾選「同訂購人」
- 送貨時段選擇（不指定/上午/下午）
- 付款方式：匯款（顯示帳號 + 必填匯款後五碼）/ 現金付款
- 手機號碼查詢訂單狀態（待付款/已確認/已出貨）
- Mobile-first RWD，手機體驗優先

## 部署教學

### Step 1：建立 Google Sheet

1. 新建一個 Google Sheets
2. 建立三個工作表，分別命名為：`商品`、`訂單`、`設定`
3. **商品** 工作表第一列填入欄位標題：

   | 商品名稱 | 五斤價格 | 十斤價格 | 二十斤價格 | 是否售罄 |
   |---------|---------|---------|-----------|---------|

   - 價格留空＝不提供該規格
   - 是否售罄填 `是` 或 `否`

4. **訂單** 工作表第一列填入欄位標題：

   | 訂單編號 | 訂購時間 | 訂購人姓名 | 訂購人電話 | 訂購人地址 | 收件人姓名 | 收件人電話 | 收件地址 | 送貨時段 | 付款方式 | 匯款後五碼 | 備註 | 商品 | 規格 | 數量 | 金額 | 訂單狀態 |
   |---------|---------|-----------|-----------|-----------|-----------|-----------|---------|---------|---------|-----------|------|------|------|------|------|---------|

5. **設定** 工作表填入 key-value（A 欄為鍵，B 欄為值）：

   | 匯款銀行 | （你的銀行名稱） |
   |---------|----------------|
   | 分行 | （你的分行） |
   | 帳號 | （你的匯款帳號） |
   | 戶名 | （你的戶名） |
   | 公告訊息 | （選填，顯示在網頁頂部） |
   | 匯款期限說明 | （例：請於下單後三日內完成匯款） |

### Step 2：部署 Google Apps Script

1. 在 Google Sheet 上方選單 → **擴充功能** → **Apps Script**
2. 把 `gas/Code.gs` 的內容全部複製貼上，取代預設的 `myFunction`
3. 點選 **部署** → **新增部署**
4. 類型選 **網頁應用程式**
5. 設定：
   - 執行身分：**我自己**
   - 存取權限：**任何人**
6. 點選 **部署**，複製產生的 **Web App URL**

### Step 3：設定前端

1. 打開 `js/script.js`
2. 找到第一行的 `API_URL`，把 `'YOUR_GAS_WEB_APP_URL_HERE'` 換成你的 Web App URL：
   ```js
   const API_URL = 'https://script.google.com/macros/s/xxxxx/exec';
   ```

### Step 4：部署前端

**方法 A：GitHub Pages**
1. 把專案推到 GitHub
2. Settings → Pages → Source 選 `main` 分支 → Save
3. 等幾分鐘就能用 `https://你的帳號.github.io/mango-order/` 存取

**方法 B：Netlify**
1. 把整個資料夾拖到 [Netlify Drop](https://app.netlify.com/drop)
2. 自動產生網址，完成

### Step 5：開始接單

1. 在商品工作表填入你的芒果品項和價格
2. 把網址分享給客人
3. 訂單會自動寫入訂單工作表
4. 在訂單工作表的「訂單狀態」欄更新狀態（待付款 → 已確認 → 已出貨），客人查詢就能看到

## 日常管理

| 操作 | 在哪裡做 |
|------|---------|
| 新增/修改商品 | Google Sheet「商品」工作表 |
| 設定售罄 | 「是否售罄」欄改為 `是` |
| 查看訂單 | Google Sheet「訂單」工作表 |
| 更新訂單狀態 | 「訂單狀態」欄改為 已確認 / 已出貨 |
| 修改匯款資訊 | Google Sheet「設定」工作表 |
| 修改公告 | Google Sheet「設定」工作表 |
