# 芒果訂購網站 — 技術規劃文件（最終版）

## 1. 技術選型

| 層級 | 技術 | 說明 |
|------|------|------|
| 前端 | HTML + CSS + Vanilla JS | 一頁式靜態網站，無需框架 |
| 樣式 | Tailwind CSS（CDN） | RWD mobile-first，快速開發 |
| 後端 API | Google Apps Script（Web App） | 免費、免伺服器 |
| 資料庫 | Google Sheets | 商品表 + 訂單表 + 設定表 |
| 部署 | GitHub Pages 或 Netlify | 靜態託管，免費 |

## 3. API 設計

所有端點共用同一個 Web App URL，以 `action` 參數區分。

### GET ?action=products — 取得商品列表與設定

```json
{
  "success": true,
  "data": {
    "products": [
      { "name": "愛文芒果", "prices": { "5": 450, "10": 850, "20": 1600 }, "soldOut": false },
      { "name": "金煌芒果", "prices": { "10": 750, "20": 1400 }, "soldOut": false }
    ],
    "settings": {
      "bankName": "台灣銀行",
      "bankBranch": "屏東分行",
      "accountNumber": "012-345678-901234",
      "accountHolder": "王大芒",
      "announcement": "今年產季預計 6 月開始出貨",
      "paymentNote": "請於下單後三日內完成匯款"
    }
  }
}
```

已售罄商品回傳但標記 `soldOut: true`（前端灰掉）。無價格的規格不出現在 prices。

### GET ?action=query&phone=09... — 用電話查訂單

```json
{
  "success": true,
  "data": [
    {
      "orderId": "MG-20260413-0001",
      "time": "2026/04/13 14:30",
      "buyerName": "王小明",
      "status": "待付款",
      "paymentMethod": "匯款",
      "deliveryTime": "上午",
      "items": [
        { "product": "愛文芒果", "spec": "十斤", "qty": 2, "amount": 1700 },
        { "product": "金煌芒果", "spec": "二十斤", "qty": 1, "amount": 1400 }
      ],
      "total": 3100
    }
  ]
}
```

### POST — 提交訂單

**請求：**
```json
{
  "action": "order",
  "buyerName": "王小明",
  "buyerPhone": "0912345678",
  "buyerAddress": "台北市大安區...",
  "receiverName": "李小花",
  "receiverPhone": "0987654321",
  "receiverAddress": "高雄市前鎮區...",
  "deliveryTime": "上午",
  "paymentMethod": "匯款",
  "bankCode": "12345",
  "note": "希望週五到",
  "items": [
    { "product": "愛文芒果", "spec": "10", "qty": 2 },
    { "product": "金煌芒果", "spec": "20", "qty": 1 }
  ]
}
```

**回應：**
```json
{ "success": true, "orderId": "MG-20260413-0001", "total": 3100 }
```

金額由 Apps Script 根據 Sheet 當前價格計算，不信任前端。

## 4. UI 結構

單一 `index.html`，兩個 tab：訂購 / 查詢。

### 訂購表單流程

1. 公告區（從 Settings 載入，空則不顯示）
2. 商品選擇區：卡片式，每張卡片一個商品，勾選規格後出現數量欄，售罄商品灰掉
3. 總額即時計算
4. 訂購人資訊：姓名、電話、地址
5. 收件人資訊：checkbox「同訂購人」→ 勾了自動帶入；不勾顯示三欄位
6. 送貨時段：不指定 / 上午 / 下午（小字：備註盡可能跟物流說，但一切按物流安排）
7. 付款方式：匯款 / 現金付款
   - 選匯款 → 顯示匯款帳號 + 匯款後五碼（必填）
   - 選現金 → 隱藏匯款區塊
8. 備註
9. 送出按鈕

### 查詢頁

輸入電話 → 查詢 → 卡片式顯示訂單（手機友善）

### RWD 要點

- Mobile-first，表單單欄排列
- 按鈕大且易點擊（min-height 48px）
- 商品用卡片不用下拉
- 查詢結果手機用卡片式呈現
- 數量用 `type="number"` + `inputmode="numeric"`
- 電話用 `type="tel"`

---

## 5. 注意事項

- GAS 免費帳號每日 20,000 次呼叫，小型訂購足夠
- GAS Web App 回傳 redirect（302→200），前端用 `fetch(url, { redirect: 'follow' })`
- 金額一律在 GAS 端重新計算，不信任前端
- 前端用 `textContent` 渲染，防 XSS
- 用 `localStorage` 暫存訂購人資訊，方便回購不用重填
